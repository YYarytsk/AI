# PianoPromoCopilot
Production-ready MVP skeleton for compliant YouTube promotion workflows for original piano compositions.

## Compliance Warning
No fake engagement automation is included. All generated suggestions require human review/approval.

## Quick start
1. `cp .env.example .env`
2. `docker-compose up -d`
3. Install .NET 10 SDK and Angular CLI.
4. Run API from `src/PianoPromoCopilot.Api` and Angular app from `client/piano-promo-copilot-client`.

See `docs/setup-mac.md` for full commands and `docs/api-endpoints.md` for endpoint map.
